# bean-jame-game-01

Castle tile assets by [Tajima](https://gtajima.itch.io/)

## Workflow

Create a new branch for the feature you are going to add. For example, feature/player.

Pull the latest changes down from main and then switch to your branch to work on your 
feature and then commit and push youur changes to GitHub and start a Pull Request.

In the world node, everything is made out of scenes. Make your own scene and 
edit within the scene. For example, player.tscn gets edited in it's own 
environment, tested in a test environment, and then it gets imported into 
the world node when it is ready.
